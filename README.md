# FocusBank website

Source for **https://dasa108.github.io/focusbank/**, the download and information page for FocusBank, an Android app that keeps distracting apps locked until you earn screen time by finishing your tasks.

- `index.html`: home page with features, privacy summary, download and install steps
- `privacy.html`, `terms.html`: privacy policy and terms
- `assets/`: stylesheet and logo

The APK is attached to the [latest release](https://github.com/Dasa108/focusbank/releases/latest). Found a problem? [Open an issue](https://github.com/Dasa108/focusbank/issues).
